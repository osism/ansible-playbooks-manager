## [v0.20230614.0] - 2023-06-14

### Added
- Initial import of playbooks and CI configuration from osism/cfg-generics
- Basic setup playbook to orchestrate full manager setup (osism/ansible-playbooks-manager#6)
- Playbook to deploy all services (traefik, netbox, manager) in a single step
- Custom ansible-lint rules for attribute order and FQCN checking (osism/ansible-playbooks-manager#4)
- `manager_service_restart` parameter to control whether the manager service is restarted (osism/ansible-playbooks-manager#14)
- Health check wait after manager service restart to ensure all containers are healthy (osism/ansible-playbooks-manager#20)
- Zuul job for ansible-lint checks (osism/ansible-playbooks-manager#9)
- Periodic-daily jobs for ansible-lint and yamllint in Zuul (osism/ansible-playbooks-manager#13)

### Changed
- Use Ansible fully qualified collection names (FQCNs) in all playbooks (osism/ansible-playbooks-manager#1)
- Use fully qualified collection names (FQCN) for all roles in playbooks (osism/ansible-playbooks-manager#18)
- Reorder `become` attribute position in playbooks for consistency (osism/ansible-playbooks-manager#2)
- Disable fact gathering for ssh pipelining and configuration update plays
- Extend ansible-core compatibility to include versions 2.13 and 2.14 (osism/ansible-playbooks-manager#5)
- Update supported Ansible versions to >=2.14.0,<2.16.0 (osism/ansible-playbooks-manager#21)
- Refactor ansible-lint rules configuration after version updates (osism/ansible-playbooks-manager#7) (osism/ansible-playbooks-manager#8)
- Enable ansible-lint rules: var-spacing, fqcn-builtins, parser-error, fqcn[keyword], template-instead-of-copy (osism/ansible-playbooks-manager#15) (osism/ansible-playbooks-manager#16) (osism/ansible-playbooks-manager#17) (osism/ansible-playbooks-manager#18) (osism/ansible-playbooks-manager#19)
- Migrate yamllint check from GitHub Actions to Zuul CI (osism/ansible-playbooks-manager#10)
- Add squash-merge mode to Zuul configuration (osism/ansible-playbooks-manager#11)

### Removed
- Python 2 playbook as Python 2 is no longer supported
- GitHub Actions workflow for ansible-lint checks, replaced by Zuul (osism/ansible-playbooks-manager#9)
- GitHub Actions workflow for YAML syntax checking (osism/ansible-playbooks-manager#10)
- Custom ansible-lint rules directory and custom rules (osism/ansible-playbooks-manager#12)
